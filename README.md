# Sakshi_Portfolio 📊

> **Modern, High-Impact Portfolio for Sakshi Rathod** — Data Analyst & AI Specialist (B.Tech AI • 9.9/10 CGPA • GDG Cloud Core Member).

A luxury warm beige and espresso-themed portfolio website featuring live interactive data dashboards (Chart.js), real-time SQL & DAX query playgrounds, curated project case studies, and an executive ATS-friendly printable curriculum vitae.

---

## 🌟 Key Highlights & Features

- **Luxury Dual Theme Aesthetic**: Warm Linen & Beige base (`#FAF6F0`) with Roasted Espresso (`#231710`) and Caramel / Amber glow accents (`#A66E46`).
- **Interactive Live Analytics Sandbox**:
  - **Meta Ad Performance**: ROAS Multiplier vs. Conversion Rate across ad placements (Chart.js).
  - **ExoHabitAI Habitability**: NASA exoplanet parameter radar index compared to Earth standards.
  - **Motorola Sales Growth**: Monthly revenue forecasting and gross profit margin line charts.
  - **Live SQL & DAX Query Playground**: Real-time multi-table query runner with simulated execution times (`18.4 ms`) and live responsive data tables.
- **Curated Projects Showcase**:
  - **Meta Ad Performance Dashboard** (Power BI, DAX, Power Query)
  - **ExoHabitAI – NASA Habitability Prediction** (Python, Scikit-learn, Flask REST)
  - **Motorola Sales Analysis** (PostgreSQL, Star Schema, Power BI)
  - **JustiMind – AI Legal Agent** (Python, LLMs, RAG, LangChain)
  - **Smart Task Dashboard** (Electron.js, JavaScript, Modern UI)
  - **AICTE GenAI & RAG Framework** (PyTorch, Transformers, Vector Search)
- **Executive ATS Resume Viewer**: Built-in interactive resume modal with 1-click **"Print / Save PDF"** support.
- **Audio Feedback Synthesizer**: Optional Web Audio API micro-haptics for interactive UI buttons.
- **Responsive & Accessible**: 100% mobile-friendly with magnetic cursor aura, ambient particle canvas, and smooth scroll reveal animations.

## 🚀 Running Locally

To run this portfolio locally:

```bash
# Clone the repository
git clone https://github.com/rathodsakshi290/Sakshi_Portfolio.git

# Navigate into the project folder
cd Sakshi_Portfolio

# Start a local HTTP server (e.g. using Python)
python -m http.server 8080
```

Open your browser and navigate to `http://localhost:8080`.
